# F1 Race Intelligence Dashboard

A responsive, beginner-friendly college project inspired by motorsport analytics dashboards.

## Features
- Dark racing-inspired interface with red highlights
- Dashboard cards for drivers, races, fastest lap, and top team
- Interactive race filter (Monaco, British GP, Italian GP, Japanese GP)
- Canvas-based bar charts (no chart library required)
- Driver leaderboard that updates when a race is selected
- Responsive mobile layout and collapsible navigation

## Important note
This project uses **illustrative sample data** for demonstration and learning. It is not connected to live Formula 1 data and should not be presented as official race results.

## How to run on a Mac
1. Download and unzip `f1_race_intelligence_dashboard.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser.
4. Recommended: install the **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.

You do not need Python or Flask to run this starter version.

## Project structure
- `index.html` — page structure and dashboard sections
- `style.css` — layout, colors, responsive styling
- `script.js` — sample data, chart drawing, filters, and leaderboard updates
